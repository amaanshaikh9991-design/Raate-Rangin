#  Features:

##  User Authentication
- Secure signup and login system
- Passwords encrypted using bcrypt
- Session-based authentication

##  Personal Music Uploads
- Every user can upload and manage their own songs
- Users can build their personal music library
- Independent music collections for each account

##  Music Management
- Store songs in the cloud
- Organize tracks easily
- Access music anytime from anywhere

##  Music Streaming
- Stream uploaded songs directly from the browser
- Smooth playback experience
- Modern music player interface

##  Cloud Hosted
- Backend deployed on Render
- PostgreSQL database hosted online
- Accessible globally 24/7

##  Secure Backend
- Environment variables for sensitive data
- Protected database connection
- Server-side authentication handling

##  Scalable Architecture
- Built using Node.js and Express
- PostgreSQL database support
- Easy to expand with playlists, likes, search, and more future features
